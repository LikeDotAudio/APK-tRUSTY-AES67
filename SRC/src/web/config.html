Node & network

Sound card (ALSA)

This plugin does not create a sound card — it opens one that exists and connects its jacks to the network. To make the network a device in your desktop's sound settings, pick Loopback PCM — Loopback (hw:CARD=AES67,DEV=1) for both input and output: your apps then play to and record from “Loopback Analog Stereo”. The stack loads that virtual card (snd-aloop) at launch — see docker logs Plugin-AES67-Loopback if it is missing.

① Card inputs → Senders → network

Mic / line in. What these channels hear is sent as your AES67 streams (TX).

② Network → Receivers → card outputs

Speakers / line out. Streams you receive (RX) are played here.

Which channel goes where is set on the MATRIX tab. Card channels count from 1; a channel the card lacks is silent.

SAP configuration

Browsing fills the Receivers tab's stream list. Announcing sends each sender that has SAP ticked on the Senders tab. Dante, RAVENNA and most AES67 gear use 239.255.255.255:9875.

RAVENNA

Senders with RAVENNA ticked are advertised over mDNS as _ravenna_session._sub._rtsp._tcp; receivers fetch the SDP with DESCRIBE rtsp://<node>:<port>/by-name/<session>. The port is carried in the mDNS record, so it need not be 554.

Senders

Card channels as a list or range: 1-8, 9,10. Up to 8 per stream. ST 2110-30 needs a conformance level: A = 1 ms ≤ 8 ch, B/C = 125 µs.
